# Linux Command Practice

## Commands Learned

1.pwd    -Displays the current directory
2.ls     -List the files or Directory
3.cd     -Change directory
4.mkdir  -Creat the directory(file)
5.touch  -Creat the file
6.grep   -Search for the text inside the file
7.find   -Search for the files and directory
8.chmod  -Change file permission
9.ps     -Displays the snapshot running Processor
10.top   -Displays the live running Processor
11.df -h -Show the usage
12.du -sh  - Shows the directroy size
13.whoami  -Displays the logged-in user 
14.hostman -Displays the Linux system name
15.uname   -Displays the Operating system name 
16.uname -a  -Diaplays the Operathing system name,Kernal,System architecture,Hostman(It shows complete information)
17.free -h   -Displays the Total RAM,Used RAM,Avilable RAM,Free RAM (It shows the RAM usage)
18.cd.. - It move to one step back
19.cd.  - It stays in currnet path
